# Identity and current state

Visible anchors: GSE-2 [page 5](../specimens/GSE-2-redacted.pdf#page=5), with additional object rules on page 6.

The record distinguishes `Objects`, `Appendations`, `World_State`, `Spatial_Board` and `History`. The visible field descriptions retain stable object names/original paragraphs, chronological referent notes, current conditions/relations, spatial holdings and prior events. Page 9 visibly checks that prior Objects/Appendations remain verbatim prefixes.
